# Hamza BX - Portfolio Website

Welcome to the personal portfolio website of **Hamza BX**, a passionate Full Stack Developer. This project is my personal space on the internet to showcase my skills, projects, and career journey.

## Features
- **Modern UI/UX:** Clean, elegant, and responsive design.
- **3D Interactions:** Uses Three.js for interactive 3D elements.
- **Smooth Animations:** Powered by GSAP.
- **Fully Responsive:** Optimized for both desktop and mobile devices.

## Tech Stack
- **Frontend Framework:** React
- **Build Tool:** Vite
- **3D Library:** React Three Fiber / Drei
- **Animation:** GSAP
- **Styling:** CSS3

## Running the Project Locally

If you want to run this project on your local machine:

1. Clone this repository.
2. Open the project folder in your terminal.
3. Install dependencies by running:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Click the local server link (e.g., `http://localhost:5173/`) to view the website.
